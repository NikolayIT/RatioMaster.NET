RatioMaster.NET 0.43

RatioMaster.NET is a small standalone application which fakes upload and download stats of a torrent to almost all BitTorrent trackers.

This means that it does not rely on your BitTorrent client (uTorrent, Azureus, BitComet, ABC and others) and it will not download or upload the files of a torrent. It can only fake the download and upload statistics reported to the tracker.

RatioMaster.NET has built-in emulations of the most commonly used BitTorrent clients: uTorrent, BitComet, Azureus, ABC, BitLord, BTuga, BitTornado, Burst, BitTyrant and BitSpirit.

Program features

  • Supports multiple torrents running in one instance.
  • Multi-OS support: Windows, Linux, Solaris, Mac OS X and Unix.
  • Automatically loads the torrent info from the torrent file.
  • Tab sessions: save the current session and load it later.
  • Very strong protection against anti-cheat scripts.
  • Good, user-friendly interface with drag and drop support for files.
  • Parses all data from all running uTorrent, Azureus, BitComet and ABC instances.
  • Selectable upload and download speeds.
  • Optional random values for upload and download speeds on every tracker update.
  • Selectable tracker response interval (the program gets this value from the tracker automatically).
  • Lots of client simulations available: the latest versions of uTorrent, BitComet, Azureus, Vuze, BitTorrent, BitLord, ABC, BTuga, BitTornado, Burst, BitTyrant, BitSpirit, Deluge, KTorrent, GnomeBT and Transmission.
  • Shows uploaded, downloaded, tracker update intervals and more, all in real time.
  • Support for custom announce and client simulation parameters.
  • Good error protection.
  • Supports different types of proxies: HTTP, SOCKS4, SOCKS4a and SOCKS5.
  • Keeps a log. If any errors occur you can send the log and I will try to fix the problem.
  • Informs you about new versions.
  • Works with almost all BitTorrent trackers.
  • And many other great features!
